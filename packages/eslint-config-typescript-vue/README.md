# @myparcel-dev/eslint-config-typescript-vue

[![@myparcel-dev/eslint-config-typescript-vue on npm](https://img.shields.io/npm/v/@myparcel-dev/eslint-config-typescript-vue?style=for-the-badge)](https://npmjs.com/package/@myparcel-dev/eslint-config-typescript-vue)

## Install

You can install `@myparcel-dev/eslint-config-typescript-vue` via your package manager of choice.

### npm

```bash
npm install --save-dev @myparcel-dev/eslint-config-typescript-vue
```

### yarn

```shell
yarn add --dev @myparcel-dev/eslint-config-typescript-vue
```

### pnpm

```shell
pnpm add --save-dev @myparcel-dev/eslint-config-typescript-vue
```

## Usage

Extend the config in your [ESLint configuration file].

Example: `.eslintrc`

```json
{
  "extends": "@myparcel-dev/eslint-config-typescript-vue"
}
```

[ESLint configuration file]: https://eslint.org/docs/user-guide/configuring
